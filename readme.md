# ✨ 반딧불이 집중 타이머 (Firefly Focus Timer)

동화 속 반딧불이가 빛나는 밤숲의 감성을 담은 **집중 타이머 웹앱**입니다.  
별도의 프로그램 설치나 인터넷 연결 없이, `index.html` 파일 하나만 더블클릭하면 컴퓨터와 스마트폰 어디서든 바로 실행할 수 있습니다.

---

## 📁 폴더 및 파일 구성

```text
1024_타이머/
 ├── index.html   # 타이머 웹앱 실행 파일 (HTML + CSS + JavaScript 통합)
 └── readme.md    # 프로그램 소개 및 사용 설명서
```

---

## ✨ 주요 기능

1. **초대형 시간 표시**
   - 빔프로젝터나 멀리서도 한눈에 남은 시간(`분:초`)이 보이도록 큼직한 황금빛 글씨로 표시됩니다.
2. **빠른 시간 선택 버튼**
   - **[5분]**, **[10분]**, **[15분]** 버튼을 눌러 자주 쓰는 시간을 한 번의 클릭으로 설정할 수 있습니다.
3. **자유로운 분(Minute) 설정**
   - 원하는 시간(1분~999분)을 직접 입력하고 **[적용]** 버튼(또는 `Enter` 키)을 눌러 타이머를 맞출 수 있습니다.
4. **시작 / 일시정지 / 초기화**
   - 언제든 타이머를 멈추거나 처음 설정한 시간으로 되돌릴 수 있습니다.
5. **마지막 10초 긴박감 효과**
   - 남은 시간이 **10초 이하**가 되면 숫자가 밝은 산호빛 빨간색으로 바뀌며 두근거리듯 커졌다 작아집니다.
6. **종료 문구 및 알림음**
   - 시간이 `00:00`이 되면 **"✨ 시간 종료! ✨"** 문구가 나타나고, 외부 음원 파일 없이도 브라우저 내장 신디사이저(Web Audio API)를 통해 맑은 알림음이 울립니다.

## 🎨 디자인 특징 (반딧불이 밤숲 스타일)

- **배경:** 깊은 밤하늘의 인디고·보라색 그라데이션과 은은하게 떠다니는 반딧불이 애니메이션
- **색상 포인트:** 
  - 타이머 숫자: 반딧불이의 따뜻한 황금빛 네온 효과
  - 시작 버튼: 일러스트 속 소녀의 드레스를 닮은 화사한 핑크 컬러
- **반응형 화면:** PC 모니터, 빔프로젝터, 태블릿, 스마트폰 화면 크기에 맞춰 자동으로 글씨와 버튼 크기가 조절됩니다.

---

## 🚀 실행 방법 (Windows 기준)

1. 컴퓨터 바탕화면에 **`1024_타이머`** 폴더를 만듭니다.
2. 해당 폴더 안에 **`index.html`** 파일과 이 **`readme.md`** 파일을 저장합니다.
3. **`index.html`** 파일을 마우스로 **더블클릭**하면 기본 인터넷 브라우저(크롬, 엣지 등)가 열리면서 타이머가 바로 실행됩니다.
